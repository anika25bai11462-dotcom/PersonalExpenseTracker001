

 Problem Statement is given by the - 
Personal financial management often becomes unorganized when using manual paper logs or overly complex mobile applications. Individuals need a clean, self-contained desktop system to record daily income and expenses, set category budget limits, receive real-time spending overload alerts, and export structured data for offline backup.

 Scope of the Project
The scope of this project is limited to a modular, offline Java Command Line Interface (CLI) application. It includes user transaction processing, dynamic budget threshold calculations (85% warning and 100% cap limits), financial summary analytics, and CSV persistent file output. It does not include external cloud databases or graphical user interface (GUI) components.

Target Users
- Students and working professionals seeking a lightweight offline tool for personal financial tracking.
- Users who require structured financial analysis and CSV reports without software bloat or network dependency.

 High-Level Features
- Transaction Management : Capability to log income and expense entries with validation, category tagging, and automatic timestamps.
- Budget Control Engine: Capability to set monthly category budget caps and evaluate expenditure against spending limits.
- Financial Analytics: Capability to calculate net savings, total cash flows, and category spending distributions.
- *CSV Data Storage : Capability to export transaction histories into structured CSVdsjdjdv files for persistent local storage.
